The Plan: POC 1
This POC is focused on building the foundational infrastructure to stream video from tablets and perform real-time analysis in the cloud, creating a data lake of operational activity.

Objectives:
To establish a reliable, real-time video streaming pipeline from 10 Android tablets to the AWS cloud
To perform server-side object detection for both worker presence and object counting
To enable tablet-based controls for operators to start/stop counting sessions
To detect and log operator presence/absence correlation with counting status
To create a structured data lake storing all video frames, detection events, counts, and metadata
Scope:
Data Ingestion:
Devices: 10 Samsung SM-X210 tablets will be configured to stream H.264 video.
Protocol: Video will be streamed to AWS using Kinesis Video Streams.
Tablet interface to start/stop counting sessions
Data Processing:
Compute: An AWS Fargate container will run a GStreamer pipeline for each of the 10 video streams.
Session management: Track when counting is active vs. stopped (manually or due to absence)
Detection: The GStreamer pipeline will decode the video and run an object detection model to identify worker presence (or absence).
Data Lake & Storage:
Raw Data: Raw video frames and snapshots from detection events will be stored in Amazon S3.
Detection Logs: Structured logs of detection events (starts, stops, counts, metadata) will be stored in Amazon DynamoDB.
Querying: Data will be processed by a daily batch job (AWS Glue or Lambda) and indexed so it can be queried using Amazon Athena.
User Interface:
A simple web interface will be built using React and Amplify. It will show the online/offline status of each tablet, display real-time and historical detection counts, and allow a user to start and stop the video streams.

Plan & Deliverables:
A functioning system with 10 active and stable video streams from the tablets.
A demonstrated capability for real-time presence detection on all 10 streams.
Tablet interface allowing operators to start/stop counting sessions
A basic monitoring dashboard with the ability to export analytics data via Amazon Athena.

The Plan: POC 2
This POC builds directly on the detection events from PoC #1 to create a comprehensive data orchestration system that integrates with your existing operational platform.
Objectives:
To orchestrate and process all detection events from PoC #1 into actionable business notifications
To establish reliable API integration with existings platform for real-time operational alerts
To implement structured data storage optimized for both real-time access and historical analysis
To provide a simple AI-powered interface for managers to query stored operational data
Scope:
Data Orchestration:
AWS EventBridge to capture all detection events from PoC #1
Fargate Tasks to process and transform events into business logic
SQS/SNS for reliable message delivery and retry mechanisms
Data Storage Architecture:
DynamoDB for real-time event logs and session state
Amazon Timestream for time-series data (presence duration, patterns)
S3 with lifecycle policies for long-term snapshot archival
Data partitioning strategy for efficient queries
API Integration:
REST API endpoints for your existing platform
Webhooks for: Worker session start/stop, Absence alerts (>5 min), Daily summary statistics
API Gateway with authentication and rate limiting
Lightweight AI Features:
Simple Bedrock integration for natural language queries
Pre-built query templates for common questions
Basic dashboard showing key metrics without requiring AI
Plan & Deliverables:
Fully functional data orchestration pipeline handling 10 concurrent video streams
API integration sending real-time notifications to your existing platform
Demonstrated data storage with optimized query performance
Simple AI assistant for basic operational queries
